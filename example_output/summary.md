# CrewAI Summary

**Definition:** CrewAI is an open-source framework for orchestrating autonomous AI agents and building production-ready, multi-agent workflows.

## Key Ideas

* **Crews provide collaborative intelligence:** Crews are teams of specialized, role-playing AI agents that collaborate and delegate tasks to solve complex problems.
* **Flows provide structured control:** Flows serve as the backbone of your application, managing state, handling logic (such as loops and branching), and controlling event-driven execution.
* **Balanced architecture:** In a complete application, Flows act as the manager defining the overall process, while Crews do the heavy lifting by performing autonomous tasks assigned by the Flow.
* **Flexible tool connectivity:** Agents can be connected to external tools, APIs, databases, and local tools to perform their work.
* **Production and enterprise focus:** The framework is built for scalability and security, while being optimized to minimize token usage and API calls.
